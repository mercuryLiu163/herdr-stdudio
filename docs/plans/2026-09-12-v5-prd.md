## F1 对话显示效果复刻（分屏 · 对话视图）

### F1a turn 头部元数据条（参考截图首行）
每个 turn（相邻 user 块之间的块序列）渲染头部条 `[data-testid="turn-header"]`：
模型头像色块（agent kind 首字母，hash 色相）+ agent 显示名 + 最后更新时间(HH:MM:SS) +
统计 chips。**统计只能用可推导数据，缺什么就不显示什么**（优雅降级，禁止编造）：
- 步数 = 该 turn 内 tool 块数（"N 步"）
- 文件数 = 该 turn 内出现的去重文件路径数（"N 文件"）
- 时长 = 该 turn 内 meta 行（Baked/Worked for Ns）若存在则显示
- token/±行数：herdr 转写无此数据，**不渲染**
头部条右侧 `>` chevron 可折叠/展开该 turn 正文（默认展开，折叠态只留头部条）。

### F1b 逐 turn 修改文件卡片（mcode TurnFilesCard 风格）
文件路径信息从 tool 块内**聚合上收到 turn 尾部卡片** `[data-testid="turn-files-card"]`：
- 折叠态文案「本轮修改 N 个文件」（N=去重路径数，0 则不渲染卡片）
- 展开列出 `[data-testid="turn-file-row"]`（文件 chip，目录着色沿用 V4）
- tool 块内部保留 `tool-chip` 摘要行；V4 的 `tool-files` 内嵌网格移除（由本卡片取代）
- turn 边界 = user 块（或 meta 分隔）之后到下一个 user 块之前

### F1c markdown 表格与排版（对齐参考截图）
- 表格（marked GFM 已支持）渲染为参考图样式：全边框、表头底色、单元格 padding、
  圆角容器 `[data-testid="chat-immersive"] table` 必须有可见边框（测试断言 computed
  border-width > 0）
- 排版微调对齐参考：正文 14px/行高 1.75、turn 间距 > 块间距、链接色 accent、
  行内代码底色块
- V4 的全部解析规则与 testid（thinking-row/chat-meta/tool-chip 等）保持不变

### 验收：v5 spec F1 组（turn-header 统计、折叠交互、turn-files-card 折叠/展开与
文件行数、表格边框、V3/V4 回归不回退）

## F2 右侧栏应用化

**描述**：右侧栏顶部新增应用切换条 `[data-testid="sidebar-apps"]`（参考 mcode 右上
图标条），本版含两个应用：
1. **文件**（现有 RightSidebar 内容迁移，testid 全保留：cwd-select/file-tree/
   file-preview/open-external）
2. **Git** `[data-testid="sidebar-panel-git"]`：主进程 IPC `git:status {cwd}` →
   `git -C <cwd> status --porcelain=v1 -b` 解析为 `{branch, entries:[{x,y,path}]}`；
   渲染分支名 `[data-testid="git-branch"]` + 变更列表 `[data-testid="git-file"]`
   （状态字母着色：M 黄 / A 绿 / D 红 / ?? 灰）。非 git 目录显示明确空态。
   点击文件行 → 用 `git:diff {cwd, path}`（`git diff -- <path>`，untracked 用
   `git diff --no-index /dev/null` 的替代方案或显示 "新文件"）在 file-preview 复用
   区显示差异文本（等宽 pre）。
3. 应用切换条为图标按钮（文件夹 / Git 分支图标），active 态高亮；选择持久化
   （localStorage `herdr-studio-sidebar-app`，默认 files）。

### 验收：v5 spec F2 组（切换条存在且可切、files 应用回归、git 应用对种子仓库
显示分支与变更文件、点击变更文件显示 diff、非 git 目录空态）
