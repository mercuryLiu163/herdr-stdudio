# Herdr Studio V6 — PRD 与验收标准

日期：2026-09-12 · 基线：`v5` 标签 · 流程：TDD（`tests/playwright/v6-features.spec.mjs` 契约先行）

## 背景诊断（对照 mcode 参考图的差距）

V5 的对话视图仍是"卡片 + 壳"，与参考的"连续文档"气质不同。逐项：

| # | 现状（丑的来源） | 目标（参考图的样子） |
|---|---|---|
| 1 | assistant 正文用等宽（终端）字体 | **散文无衬线**；等宽仅限 code/行内代码/文件路径 chip |
| 2 | TUI 树形字符漏出（`└ Set model to...`） | 树形/框线字符（└ ┌ │ ├ ──）剥离，不出现 |
| 3 | 工具块 = 全宽灰色横幅条，且散文被误分类为工具（"Looks" 芯片） | 工具 = **紧凑单行活动行**（小圆点 + 小号彩色工具名 + 摘要，无边框无底色或极淡），默认收起；无 marker 的散文行归回 assistant |
| 4 | turn 头部 = 有边框灰盒 | turn 头部 = **无边框内联行**（20px 头像 + 名称 + 时间 + 浅灰统计文字 + chevron），紧贴正文 |
| 5 | 垂直间距过大、块间都是"盒子" | 连续文档流：turn 间距 ~18px、块间距 ~10px、头部与正文 6px；除 user 气泡与 code 块外**无任何盒子底色** |
| 6 | 用户气泡粉色调 | 中性底（surface-raised）、无彩色调、圆角 14px、右对齐、max-width 72% |

## F1 排版去卡片化（CSS 为主）

- **字体分层**：`.chat-immersive` 内 assistant/user/thinking/meta/turn-header 一律
  `var(--font-ui)`；`code/pre/diff/文件路径 chip` 才可用 `var(--font-mono)`
  （测试断言 msg-assistant 的 computed font-family 不含 mono 族名）
- **去盒**：turn-header 无 border/background；tool 活动行无 border（hover 才显极淡
  底色）；thinking/meta 保持无盒
- **工具行重设计**：`[data-testid="msg-tool"]` = 单行 flex（8px 彩色圆点 + 工具名
  （12px 彩色，沿用 hash 色相）+ 摘要 13px 灰 + 右侧时长若有）；点击展开详情区
  （左侧 2px 缩进导线 + 12.5px 内容），**行本身不再承载正文**
- **user 气泡中性化**：background `var(--surface-raised)`、去彩色边、文字
  `var(--font-ui)` 13.5px
- **间距令牌**：`--chat-turn-gap: 18px`、`--chat-gap: 10px`、turn-header 与正文
  6px；meta 分隔线高度减半（更轻）
- 保留：turn 聚合/turn-header 内容/turn-files-card/表格样式/statistics 降级规则

## F2 解析质量修正

1. **树形字符剥离**：行首 `└ ┌ │ ├` 及 `──` 连线（含空格组合）剥离后再分类；
   `└ Set model to...` → assistant 正文 "Set model to..."，无 └ 残留（测试断言）
2. **工具误分类收紧**：tool 判定仅接受 `● ⏺ • ◆` marker 前缀；marker 后的首个
   词组作为工具名需 ≤3 词且非句子开头词（如 "Looks/It/The" 开头的一律不算工具名
   → 整块归 assistant）；marker 行之后的**无 marker 自然行并回 assistant**（除非
   构成 V4 的文件列表/代码围栏）
3. 其余 V4/V5 规则（thinking/meta/页脚/echo 链/文件网格聚合）保持

## 验收（v6 spec，7 例）

- F1-1 msg-assistant computed font-family 不含 mono；`└`/`│` 字形全页不出现
- F1-2 turn-header 无边框（borderWidth 0）且与正文垂直距离 ≤ 10px
- F1-3 msg-tool 行高 ≤ 32px 且无边框；点击展开详情可见
- F1-4 user 气泡背景色 == var(--surface-raised) 计算值（中性）
- F1-5 间距：相邻 turn 的边界距 ≤ 24px
- F2-1 种子散文误分类修复：无 "Looks" 工具芯片，该文本出现在 msg-assistant
- F2-2 `└ Set model to glm-5.2` 种子 → assistant 块含 "Set model to glm-5.2" 且
  不含 "└"
- 既有 47 用例 + run-all 全绿；typecheck 通过；无新增依赖
