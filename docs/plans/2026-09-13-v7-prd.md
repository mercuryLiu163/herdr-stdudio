# Herdr Studio V7 — 分屏对话数据流重排

日期：2026-09-13 · 基线：v6 · 参考：mcode `主面板数据流显示`（https://github.com/huangbh2020/mcode.git）

## 目标

分屏模式的「对话」视图必须是**重新排版的对话数据流**，不是 TUI 原文搬家。
数据源仍是 herdr `recent-unwrapped` 解析；视觉对齐参考图：

1. 用户消息 = 右对齐可折叠卡片（标题行 + markdown 正文），不是等宽终端行
2. 回合分隔 = 居中 hairline 上的时间/时长丸，不是全宽灰盒
3. 助手 = 连续文档（列表、绿色 URL chip、行内代码），无树形字符、无终端框线

统一（mosaic）布局本版不改；原始输出开关保留。

## F1 用户卡片

- `[data-testid="msg-user"]` 右对齐，max-width 72%
- 单行短消息：中性气泡（沿用 v6 surface-raised）
- 多行 / markdown 续行：可折叠卡片
  - 标题 = 首行截断，左侧小图标，右侧 chevron
  - 展开正文走 `renderMarkdown`（列表、链接）
- 解析：`❯` 用户行之后，结构续行（`- ` / `* ` / `1. ` / `URL:` / `https://` / 缩进）并入同一 user 块，直到 tool/meta/thinking/下一条用户

## F2 回合分隔

- `[data-testid="turn-header"]` 仍无边框、无盒底（v6 契约）
- 内部 `[data-testid="turn-pill"]` 水平居中，压在 1px hairline 上
- 丸内保留 v5 文本：agent 名、HH:MM:SS、时长、N 步、N 文件；chevron 折叠正文
- 时长优先显示为 `Xm Ys`（仅当解析得到）

## F3 助手文档

- 裸 `http(s)://` URL 自动成链
- `.chat-md a` 为绿色 chip（`--ok`），等宽 12px，无下划线
- 行内 `code` 保持中性底；助手正文无衬线

## F5 Composer 状态栏（复刻 mcode 底部分段胶囊；设计语言见 high-end-visual-design / aceternity-ui 技能）

Double-Bezel 嵌套外壳（wash 底 + 发丝 ring + 大圆角），分段间发丝竖线，动效一律 cubic-bezier(0.32,0.72,0,1)、按压 scale(0.98)；GPU 安全：动画只许 transform/opacity。

分段（左→右，映射 herdr 真实能力，不做假功能）：
1. `[data-testid="toolbar-attach"]` 引用文件：弹出 cwd 一级文件浅列表，点选插入 `@<相对路径> ` 到输入框光标处
2. `[data-testid="toolbar-target"]` 目标 ∨：下拉列当前 tab 全部 pane，选择切换输入目标（与 input-target 同字段双向同步）
3. `[data-testid="toolbar-view"]` 视图 ∨：对话 / 原始输出（与既有 view 分段同字段）
4. `[data-testid="toolbar-model"]` 模型 ∨（仅 agent pane）：该 kind 模型预设下拉，选择立即发送 `/model <名>`（走 V4 斜杠通道）
5. `[data-testid="toolbar-status"]` 状态环：working=转圈 / idle 绿 / blocked 琥珀 / done 蓝 + 状态词
6. `[data-testid="send-button"]` 发送：Button-in-Button（主胶囊右端内嵌 28px 圆形 accent 钮，hover 内圆位移微放大，active scale(0.98)）

下拉菜单 = 浮层玻璃面板（大扩散低透明阴影），开合 160-220ms 自定义曲线。

## F6 thinking 沉浸化（ZCode 式转圈）

- agent working 期间：turn 内全部 thinking 块合并为一条实时行 `[data-testid="thinking-live"]` = 纯 CSS spinner（`[data-testid="thinking-spinner"]`，transform 旋转）+ 「思考中 Ns」；思考内容不展开不逐行下坠
- turn 结束（idle/done/blocked）：spinner 移除，定格「思考 Ns」静态行（保留点击展开占位）
- 流式到达多条 thinking 时实时行数恒 ≤ 1；最终结果照常流入主体数据流区

## F7 卡顿根修（硬性评审项）

1. spinner 一律 CSS keyframes（transform），禁止 JS interval/setState 逐帧驱动（grep 验证）
2. 秒数时钟独立组件 `<Elapsed>`（自有 1s interval + 本地 state + memo 隔离）；断言：pane 文本流式更新前后时钟 DOM 节点身份不变
3. 贴底滚动 rAF 调度，禁止文本 tick 内同步读布局
4. turn-header 时间 tabular-nums，仅 updatedAt 变化时更新
