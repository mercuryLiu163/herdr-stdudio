## F1 对话排版规范化（TUI → 应用排版转换）

**原则**：terminal 内容**不得原样照搬**；一切 TUI 结构先解析为语义块，再由应用以
统一的排版尺度渲染。缩进/间距/层级全局一致。

### 解析规则（chat-parser v4，在 V3 基础上扩展）
1. **thinking 行**：`Thought for Ns…` / `Thinking…`（含可选 `(ctrl+o to expand)`
   后缀）→ 独立 `thinking` 块，渲染为可折叠的弱化行
   `[data-testid="thinking-row"]`（时钟图标 + "思考 Ns"，点击展开占位说明），不再
   作为 assistant 正文出现
2. **meta 行扩展**：`✻ Baked for Ns` / `Worked for Ns` / `… in Ns` 状态行 → 归入
   `meta`（居中分隔线渲染），不得出现在任何 msg 块正文里
3. **TUI 页脚/状态栏**：`▸▸ …`、`? for shortcuts`、`bypass permissions on
   (shift+tab to cycle)`、`※`/`✻` 开头的装饰行（非 meta 格式的）→ **整行丢弃**
4. **工具输出的多列列表**：tool 块内连续 ≥3 行、每行 ≥2 个空白分隔的短 token
   （文件/目录名特征：含 `.`/`/` 结尾或出现在已知 ls 语境）→ 重排为
   `[data-testid="tool-files"]` 网格（`grid-template-columns: repeat(auto-fill,
   minmax(160px, 1fr))`），每项一个文件 chip，目录以 `/` 结尾着色区分——多列宽度
   不齐的问题由 grid 布局根除
5. **排版尺度统一**：全部块类型共用同一排版常量（左基线对齐、段间距 12px、
   嵌套缩进固定 1 档 20px）；user 气泡/assistant/tool/code/thinking/meta 的
   padding/indent 全部来自同一组 CSS 变量（`--chat-indent`、`--chat-gap` 等），
   禁止块级各自为政（评审项）

### 验收（v4 spec F1 组）
- 种子转写包含上述全部模式后：`thinking-row` 存在且正文不含 "Thought for"；
  "Baked for" 不出现在任何 `[data-testid^='msg-']`；页脚行整体不存在；
  文件列表位于 `tool-files` 网格内且子项数量正确
- 排版一致性：所有 `[data-testid^='msg-']` 块的 `margin-left` 一致（浮点相等断言）

## F2 斜杠命令面板（Grok bot 风格）

**描述**：composer 输入以 `/` 开头时弹出命令建议面板，键入即过滤；↑↓ 或点击选择，
Enter/Tab 选中回填输入框（不直接发送），再次 Enter 发送——解决"输入 /model 后
agent 的交互选择器在对话视图里无法操作"的问题：命令以普通文本发送给 agent，agent
在 TUI 里的后续交互仍走既有 raw 视图/按键通道。

**命令数据源**（manifest 无命令元数据，实测）：静态表 `src/slash-commands.ts`，
按 agent kind 子串匹配：`claude` → /model /status /clear /compact /cost /help
/review /doctor；`codex` → /model /status /approvals /clear /compact /init /diff
/help；`gemini` → /model /stats /clear /help /tools；兜底通用集（/help /status
/model /clear）。每项 `{cmd, desc}`。

**交互细节**：输入为空或非 `/` 开头时面板不出现；过滤为前缀匹配（`/mo` →
/model）；高亮项默认第一个；Esc 关闭面板；`blur` 关闭；选中回填后面板消失。
仅 agent pane 显示（shell pane 无命令语义，不弹）。

### 验收（v4 spec F2 组）
- agent pane 聚焦 composer 输入 `/` → `[data-testid="slash-palette"]` 出现，
  `[data-testid="slash-item"]` ≥ 4 项且含 /model
- 续输 `/mo` → 仅剩 /model；Enter 回填输入框为 `/model` 且面板关闭、**未发送**
- 再次 Enter → 发送，server 侧 pane 输出含 `/model`
- shell pane 输入 `/` → 面板不出现
